# UI_DECISIONS.md — Решения по дизайну UI для TegamCAL Stage 1

Документ фиксирует все архитектурные и визуальные решения по UI прототипа.
Принят: 2026-05-23. Статус: утверждено пользователем.

---

## 1. Общая концепция

- **Тип интерфейса:** Dashboard (единое окно, всё видно сразу)
- **Структура:** Гибрид — постоянная шапка со статусами + центральная рабочая область, меняющаяся по этапам
- **Целевая аудитория:** руководство компании (демо) + метрологи/калибровщики (реальные пользователи)
- **Окно:** фиксированный размер, ориентир — ноутбук 15" Windows 10. Полноэкранный режим не нужен.
- **Целевое разрешение:** 1280×800 (стандартный 15" ноут)

## 3. Цветовая схема

### Тема
**Только тёмная.** Светлой версии не требуется.

### Акцентный цвет
**Cyan** (#00BCD4 или близкий) — для активных элементов, кнопки Start, выделения активной точки, прогресс-индикатора, заголовков.

### Статусные цвета — пастельные (приглушённые)
- 🟢 **PASS / Connected / Success** — пастельный зелёный
- 🔴 **FAIL / Disconnected / Error** — пастельный красный
- 🟡 **Warning / Warming up / Skipped** — пастельный жёлтый/янтарный
- ⚪ **Idle / Not started** — нейтральный серый

### Фон
Тёмно-серый (не чисто чёрный) — типичный фон инженерного ПО (Keysight BenchVue, Tektronix).

---

## 4. Шрифты

- **Основной интерфейс** (кнопки, заголовки, лейблы): **Segoe UI** (системный Windows, из коробки)
- **Цифры, измерения, таблицы, показания приборов:** **моноширинный** (Consolas или JetBrains Mono)
- **Отдельного "табло" текущего измерения нет** — все значения видны в таблице измерений

## 5. Компоновка дашборда (Вариант A — "приборная панель")

```
┌────────────────────────────────────────────────────────────┐
│ ШАПКА: статусы приборов + поля ввода + dropdown техника   │
├────────────────────────────────────────────────────────────┤
│ СТЕППЕР: ① As Found ─ ② Adjust ─ ③ As Left ─ ④ Report   │
├──────────────────┬─────────────────────────────────────────┤
│                  │                                         │
│  СПИСОК ТОЧЕК    │      ТАБЛИЦА ИЗМЕРЕНИЙ 4×5             │
│  (слева)         │      (главная рабочая область)          │
│                  │                                         │
│  ● Point 1 — 2Ω  │                                         │
│  ● Point 2 — 20Ω │                                         │
│  ● Point 3 — 200Ω│                                         │
│  ● Point 4 — 2kΩ │                                         │
│                  ├─────────────────────────────────────────┤
│                  │  ЛОГ СОБЫТИЙ (компактный, 3-4 строки)  │
│                  │                          [View Full Log]│
├──────────────────┴─────────────────────────────────────────┤
│                   [START]  [STOP]                          │
└────────────────────────────────────────────────────────────┘
```

### Зоны интерфейса

**Шапка (top bar):**
- Статусы приборов — средняя детализация: `🟢 Tegam 1750 (COM3)   🟢 Arduino (COM4)   [⟳ Reconnect]`
- Поля ввода (редактируемые прямо в шапке, Вариант C):
  - Температура (°C)
  - Относительная влажность (RH, %)
  - Серийный номер калибруемого прибора
- Dropdown техника — выпадающий список из конфига

**Степпер (под шапкой):**
- 4 шага: As Found → Adjust → As Left → Report
- Текущий шаг — cyan кружок
- Пройденный шаг — зелёная галочка
- Будущий шаг — серый кружок
- Пропущенный Adjust (если As Found весь PASS) — подсвечивается **"Skipped"**
- Setup как отдельный шаг **НЕ нужен**
- Warmup — **не шаг степпера**, а информационное всплывающее окно при запуске программы (закрывается кнопкой ОК или X)

**Список точек (слева):**
- Вертикальный список 4 строк (заделом на расширение до 11)
- Формат: `● Point 1 — 2 Ω`
- Активная точка — подсветка cyan
- **Кликабельны в режиме Adjust** — клик = переключение реле на эту точку
- В режимах As Found / As Left — некликабельны, только индикация

**Таблица измерений (центр, главная область):**
- Размер: 4 строки (точки) × 5 столбцов (измерения) + Mean + U(k=2) + Status
- Шапка таблицы: `Point | #1 | #2 | #3 | #4 | #5 | Mean | U(k=2) | Status`
- Ячейки заполняются в реальном времени по мере поступления измерений
- Каждое отдельное измерение со своим цветным статусом (зелёный/красный)
- Итоговый статус строки — отдельная колонка справа
- Цифры — моноширинным шрифтом, выровнены по разрядам

**Лог событий (под таблицей):**
- Компактный, 3-4 строки видны со скроллом
- Формат строки: `[14:23:45] LEVEL  Сообщение`
- Уровни: INFO (серый), WARN (жёлтый пастельный), ERROR/FAIL (красный пастельный), PASS/SUCCESS (зелёный пастельный)
- Кнопка **"View Full Log"** — открывает отдельное окно с полным логом + кнопкой "Сохранить в файл"

**Кнопки управления (низ):**
- **Start** — крупная, cyan, запускает текущий этап
- **Stop** — пастельный красный, прерывает с подтверждением
- **Pause НЕ нужен**
- **New Calibration НЕ нужен** — после Report программа сама предлагает начать новую

## 6. Поведение этапов

| Этап | Тип | Описание |
|------|-----|----------|
| **As Found** | Автомат | 5 измерений × 4 точки. Реле переключаются программно. Все данные пишутся в таблицу. |
| **Adjust** | Полуавтомат | Запускается ТОЛЬКО если в As Found хотя бы одно измерение FAIL. Техник кликает мышкой на точку в левом списке → программа подаёт нужный эталон. Tegam на своём экране показывает что подать, техник нажимает Enter на панели Tegam. Программа НЕ автоматизирует сам процесс adjustment в приборе (защита Tegam от калибровки через порт). |
| **As Left** | Автомат | Полная повторная процедура как As Found. Цель — все строки зелёные. |
| **Report** | Просмотр | Предварительный просмотр отчёта, выбор подписи (фамилия из dropdown), сохранение в xlsx. |

**После Report:** программа предлагает начать новую калибровку.

## 7. Конфигурационный файл

### Формат
**Excel (.xlsx)**, один файл с тремя листами. Расположение: `./config/config.xlsx` в папке проекта.

### Лист "Technicians"
```
| ID | Name           | Position             | Active |
|----|----------------|----------------------|--------|
| 1  | Иванов И.И.    | Метролог 1 кат.      | YES    |
| 2  | Петров П.П.    | Метролог 2 кат.      | YES    |
```
Для dropdown берутся только записи `Active = YES`.

### Лист "References"
```
| Point | Range  | Nominal | Unit | Resolution | Res_Unit | Serial      | Tol_% | Tol_Counts | Relay |
|-------|--------|---------|------|------------|----------|-------------|-------|------------|-------|
| 1     | 2 Ω    | 2.0000  | Ω    | 100        | µΩ       | RES-2R-001  | 0.02  | 2          | 1     |
| 2     | 20 Ω   | 20.000  | Ω    | 1          | mΩ       | RES-20R-001 | 0.02  | 2          | 2     |
| 3     | 200 Ω  | 200.00  | Ω    | 10         | mΩ       | RES-200R-01 | 0.02  | 2          | 3     |
| 4     | 2 kΩ   | 2.0000  | kΩ   | 100        | mΩ       | RES-2K-001  | 0.02  | 2          | 4     |
```

### Лист "Settings"
```
| Parameter              | Value |
|------------------------|-------|
| Tegam_COM_Port         | COM3  |
| Tegam_Baudrate         | 9600  |
| Arduino_COM_Port       | COM4  |
| Arduino_Baudrate       | 9600  |
| Measurements_Per_Point | 5     |
| Warmup_Minutes         | 30    |
```

### Формула расчёта допуска (PASS/FAIL)

Допуск Tegam 1750 задаётся в виде `±(% of reading + N counts)` согласно datasheet.

```
deviation = |reading - nominal|
tolerance_abs = nominal × (Tol_% / 100) + Tol_Counts × Resolution_in_base_unit
PASS если deviation ≤ tolerance_abs
```

**Пример для Point 2 (20 Ω, 0.02%, 2 counts, resolution 1 mΩ):**
```
Tol_% часть:     20 × 0.0002 = 0.004 Ω
Tol_Counts часть: 0.001 × 2 = 0.002 Ω
Полный допуск:   ±0.006 Ω
```

### Обработка отсутствия / повреждения конфига (Вариант A)

При запуске программы, если `config.xlsx` отсутствует или невалиден, показать диалог:
- 🔧 **Edit config** — открывает `config.xlsx` во внешнем Excel (или предлагает выбрать)
- 📂 **Browse for config file** — диалог выбора другого файла
- ❌ **Exit** — закрыть программу

Программа НЕ редактирует конфиг сама. Встроенный редактор отложен на Stage 2.

## 8. Масштабирование на Stage 2

UI спроектирован с учётом будущего расширения:

| Параметр | Stage 1 | Stage 2 |
|----------|---------|---------|
| Точек калибровки | 4 | 11 (весь диапазон Tegam 1750) |
| Подключение | 2-провод | 4-провод (Kelvin) |
| Коммутатор | Arduino + 4 реле | Keithley 2750 + карты 7702 |
| UI-список точек | 4 строки | до 11 строк (та же разметка) |
| Конфиг | `config.xlsx` | тот же, добавляются строки в References |

**Главный принцип:** UI оперирует понятиями "Point N", а не "Relay N". Переход на Stage 2 меняет только бэкенд коммутации, UI трогать почти не придётся.

---

## 9. Что НЕ делаем в этом прототипе

- ❌ Светлая тема
- ❌ Полноэкранный режим
- ❌ Pause во время прогона
- ❌ Звуковые сигналы
- ❌ Setup как отдельный шаг степпера
- ❌ Встроенный редактор конфига (только внешний Excel)
- ❌ Кнопка "New Calibration" в шапке (предложение само возникает после Report)
- ❌ Подробный статус приборов с baudrate (только COM-порт)
- ❌ Атмосферное давление в полях ввода
- ❌ Анимация "бегущего огонька" между реле (только подсветка активной точки)
